 🏦 그냥전당포.com  사용법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 시작하기
  1. 「시작.bat」 더블클릭 (Python 3 필요, 외부 패키지 설치 불필요)
  2. 브라우저에서 http://localhost:8080 접속 → 유저 페이지
  3. http://localhost:8080/admin 접속 → 첫 실행이면 관리자 비밀번호 설정

■ 페이지 구성
  [유저 페이지 /]
    - 판매 물품: 사장님이 등록한 판매 목록. [주문] 누르면 구매신청 폼에 자동 입력
    - 감정신청(팔래요): 닉네임/물품/수량 + 전달방법(직접 전달 / 우편으로 보내둠).
      희망가 입력 없음 — 사장님이 감정 후 감정가를 입력하면 '내 신청 조회'에 표시됨
    - 구매신청(살래요): 가격은 정가 고정(입력 없음). 정가 주문은 선입금 방식 —
      먼저 인게임 입금 후 입금내역 캡쳐를 첨부해야 신청됨(드래그/불러오기).
      신청 후 "입금 확인 후 우편으로 보내드립니다" 안내. 목록에 없는 물품은 캡쳐 없이 자유 신청 가능
    - 내 신청 조회: 닉네임으로 처리 상태 + 사장님 답변 확인

  [관리자 페이지 /admin]
    - 들어온 물품: "우편으로 보내둘게요"로 신청된 물품 목록 → 게임 우편함 확인 후 [수령 확인]
    - 신청 관리: 상태 변경(대기/승인/거절/완료) + 감정가 입력(감정신청) + 유저에게 보일 답변 작성
      각 신청은 [삭제] 버튼으로 바로 지울 수 있음
    - 재고 관리: 판매 물품 등록/수량/숨김/삭제
      ※ 재고에서 [주문]으로 들어온 구매신청을 "완료" 처리하면 재고 수량이 1 줄어듦
    - 설정: 공지사항, 영업중/휴업중, 비밀번호 변경

■ 데이터
  - 모든 데이터는 data\pawnshop.db 파일에 저장됨 (백업 = data 폴더 복사)
  - 입금내역 캡쳐 이미지는 data\uploads\ 폴더에 저장됨 (관리자만 볼 수 있음)
  - 감정/구매 신청 기록은 접수 후 7일이 지나면 자동 삭제됨 (캡쳐 이미지 포함)
    → 보관 기간 변경: server.py 맨 위 RETENTION_DAYS 숫자 수정

■ 다른 사람이 접속하게 하려면 (택 1)
  ① 집 PC 상시 구동 + 공유기 포트포워딩(8080) + DDNS 또는 고정IP
     → 유저들은 http://내주소:8080 으로 접속
  ② 무료/저가 클라우드 호스팅에 올리기 (추천)
     - cloudtype.io, koyeb.com, fly.io 등에서 Python 앱으로 배포
     - 실행 명령: python server.py 8080 (호스팅이 지정한 포트로)
     - data 폴더가 유지되는(볼륨/디스크) 플랜인지 확인할 것
  ③ 도메인 연결: 가비아 등에서 "그냥전당포.com" (한글 도메인) 구매 후
     호스팅 주소로 연결하면 그냥전당포.com 으로 접속 가능

■ 포트 변경
  - python server.py 8123  처럼 뒤에 포트 번호를 붙이면 됨

■ 주의
  - 관리자 비밀번호를 잊었다면: python reset_admin.py 실행 → /admin 에서 새로 설정
    (재고/신청 데이터는 그대로 유지됨)
